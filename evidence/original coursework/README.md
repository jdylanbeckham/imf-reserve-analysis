# Original Coursework Evidence

This directory preserves recovered artifacts from the original 2025 ADTA 4240 IMF Foreign Reserve Analytics project.

These files are retained as historical evidence and should not be modified as part of the PPAD reconstruction.

## Course Context

**Course:** ADTA 4240 – Harvesting, Storing, and Retrieving Data  
**Institution:** University of North Texas  
**Original Project Date:** July 2025  
**Project:** Weyland-Yutani Reserve Intelligence Proposal / IMF Foreign Reserve Analytics

## Recovered Evidence

- `ADTA4240.Txt`
  - Preserves project outline, methodology, analytical purpose, and summary findings.

- `Weyland-Yutani Analysis.pdf`
  - Preserves the final presentation and original analytical narrative.

- `Weyland-Yutani Analysis.pptx`
  - Preserves screenshots and visual evidence of the original workflow, including Google Cloud Storage, BigQuery, SQL queries, UNPIVOT usage, and visualization outputs.

- `WeylandYutani_FinalProject_Outline.txt`
  - Preserves the original presentation structure and supporting project narrative.

## Evidence Policy

These files represent original coursework evidence.

The PPAD reconstruction will:

1. Preserve these files without modification.
2. Use them to validate original workflow, methodology, and findings.
3. Clearly distinguish original coursework from later reconstruction.
4. Avoid claiming unsupported historical work where evidence is unavailable.
5. Document all 2026 enhancements separately.

## Known Gaps

The following original artifacts have not been recovered:

- Standalone SQL query files
- Original assignment instructions or rubric
- OpenRefine transformation history
- Complete BigQuery query history

These gaps do not prevent reconstruction because the recovered presentation and data files provide sufficient evidence to establish the original workflow and analytical intent.
